# Signal Grid: base principles

- Matte graphite surfaces with warm ivory primary text and muted secondary text.
- Thin cool-gray separators establish structure without dashboard cards.
- Compact technical navigation, restrained spacing, and small corner radii.
- Plain sans-serif content typography; monospace navigation and wordmark.
- Simple line icons with accessible navigation labels and visible keyboard focus.
- A shared top bar and narrow side rail frame an empty content workspace.

Tokens live in `apps/web/src/styles/tokens.css`; typography and global layout styles remain separate. The current foundation uses no gradients, glow, glassmorphism, or animations. Maps, charts, metrics, inspectors, and tables are outside this pass.
